# 张江学园 · 七天

一个白天养成、晚上抉择的小游戏。7 天，期末考结算 GPA。

零依赖、零构建：原生 ES Modules + Canvas。数据集中在 `data.js`，改平衡只动那个文件。

## 运行

```bash
./serve.sh          # 默认 8000 端口
# 或
python3 -m http.server 8000
```

打开 <http://localhost:8000>。

> 必须走 http，不能双击 `index.html`：ES module 会被 `file://` 的 CORS 拦掉。

## 玩法

- **白天**：每天 **5 个行动点** —— 其中 **2 节必修大课每天开头自动结算**（不占自由点，两节合成一页笔记），
  剩下 **3 点自由支配**。在校园里走动（WASD / 方向键），走到光圈按 `E` 或空格交互，也可以直接点标签。
- **寝室**：一天的起点也是终点。开局和每天早晨都在这里醒来（不花行动点就能用）：
  **书桌**看属性换算、**日历墙**看学期时间轴、**室友**给你一句「今天该干什么」、**床**躺下结束白天。
- **日历活动**：每天日程排在那面墙上。当天有活动时，校园地图上会多出一个 📌 **出发点**，
  走过去按 `E`，面板先写清「知识 +6 / 心境 +6 / 体质 —」再让你决定去不去。错过只划掉一条，不扣分。
- **进楼**：走到 **CDS-1** 或 **文娱楼** 门口按 `E` → 落在大堂 → 走到电梯口 → 电梯面板按层选（**楼层之间走动不花行动点**）。
- **房间**：走进楼层，站到教室 / 球台 / 钢琴前按 `E`，先弹一个确认面板（成本 + 今日收益），点「开始」才结算。
- **角色面板**：点右侧「角色」，看三个属性各自换算成多少伤害 / 多少血；把鼠标停上去展开算式。
- **夜晚**：回到寝室，二选一。宿舍深造（知识 +，心境 −）或出门夜战（4 回合卡牌战）。
- **夜战手感**：出牌时面板会抖——打中敌人 2px，敌人反击 4px；挨打时屏幕边缘闪红。
  音效全部由 WebAudio 现场合成（不加载任何音频文件），没有 `AudioContext` 时静音但不影响结算。
- **第 7 天**：期末考，按知识与心境结算 GPA，走三个结局之一。

### 三属性，三个出口

| 属性 | 只管一件事 | 换算 |
|---|---|---|
| **知识** | 夜战伤害 | `power × (0.8 + 知识/100)` |
| **心境** | 白天收益倍率 | `0.5 + 心境/100`，收益向上取整；**不进夜战** |
| **体质** | 血量上限 | `30 + ⌊体质 × 1.2⌋` |

体质只有两个来源：**操场跑步 +4**（日常、稳定）和**日历活动**（限时、大额）。所以「想晚上抗揍」这件事
必须用白天的行动点去换，而不是白天学习顺带涨出来的。

校园里的固定点：**操场**（心境 +12、体质 +4，得「专注」下次自习 ×1.5）、**宿舍**（进寝室）、
**公告板**（小量知识 + 一段友谊）、**林 / 陈 / 周**（聊天：友谊 +、心境 +，友谊 ≥ 40 解锁支援卡）。

### 楼里有什么

| 楼 | 楼层 | 房间（各 1 AP） |
|---|---|---|
| **CDS-1** | 3F 教学楼层 | **大课教室**：知识 +7（×心境，专注 ×1.5）/ 心境 −4 / 产一张笔记卡 · **答疑角**：知识 +2 / 心境 −1 / 随机一位朋友友谊 +5（每天 1 次） |
| | 5F lab 层 · B1 gym 层 | 电梯面板上灰着（未开放） |
| **文娱楼** | 1F 活动层 | **乒乓球台**：心境 +9 / 选一位朋友友谊 +6（每天 1 次） · **斯诺克台**：心境 +8 / 友谊 +8（要 TA 当天还没聊过） · **钢琴**：真能弹，弹够 4 个音心境 +12（每天 1 次） |
| | 2F 自习层 | **自习室**：知识 +5 / 心境 −2 / **不产卡**（分数路线） |
| | 3F 静室层 | **祷告室**：心境 +15，只有心境 ≤ 45 才进得去（每天 1 次） |
| **宿舍** | 1F 寝室（单层，没有电梯） | 不花行动点：**书桌**（角色面板）· **日历墙**（7 天时间轴）· **室友 哲**（每天一句判断，不给数值）· **床**（1 AP，心境 +12，结束白天）· **门**（回校园） |

心境归零会「崩一次」，第二天自由行动点只剩 1。

### 七天的日程

5 场活动排在第 2–6 天，第 1 天留空当教学日。每个给的配比不一样，都是「花行动点换属性」：

| 天 | 活动 | 出发点 | AP | 知识 | 心境 | 体质 |
|---|---|---|---|---|---|---|
| D2 | 社团招新（陈） | 社团楼门口 | 1 | — | +8 | +6 |
| D3 | 夜跑团（周） | 操场 | 1 | — | +4 | +10 |
| D4 | 读书会（林） | 文娱楼门口 | 1 | +6 | +6 | — |
| D5 | 校队集训（陈） | 操场 | **2** | — | −5 | +18 |
| D6 | 公司走访 | 校门 | **2** | +10 | −6 | — |

体质主要就靠 D3 和 D5 这两场——所以「想晚上抗揍」是有时间窗的，不是随时能补。

## 核心机制

1. **笔记即武器**：每次大课生成一张具名知识卡；重复学到同一主题会让那张卡威力 +2（上限 14）。晚上的牌组就是你白天学的东西。
2. **社交换战力**：友谊解锁支援卡，战斗里回血 + 回心境。
3. **稀缺即决策**：3 点自由行动点 + 心境乘数 + 归零惩罚，逼你在「再学一点」和「去透口气」之间选。
   必修课只给一小份固定知识，所以分数差距全部来自那 3 点怎么花。

## 结构

```
index.html          挂载点 + 侧栏
styles.css          像素风 UI（系统字体，无外部资源）
data.js             数值 CONFIG / 地图 / 交互点 / 卡 / 敌人 / 文案
src/state.js        状态、派生数值、存读档（xorshift32 可序列化随机）
src/rules.js        行动结算 / 日历活动 / 夜晚推进 / 考试（纯函数）
src/battle.js       夜战逻辑（抽牌、出牌、敌人回合）
src/calendar.js     日历条目、当天出发点、错过判定（纯数据）
src/world.js        校园 canvas：渲染、移动、碰撞、邻近交互、可换的交互点列表
src/interiors.js    室内数据：7 张 24×15 ASCII 平面 / 交互点 / 电梯菜单（纯数据）
src/indoor.js       室内 canvas：渲染（家具按连通块整体画）、移动、碰撞、邻近交互
src/ui.js           HUD / 标签 / 日志 / 牌组 / 弹窗 / 角色面板 / 日历墙 / 活动面板 / 钢琴键
src/main.js         启动、输入、场景与阶段状态机
tests/sim.mjs       无浏览器跑 800 局：不变量 + 结局分布 + 可复现性
tests/maps.mjs      地图体检：尺寸、交互点落脚、从出生点可达、活动出发点不抢交互
serve.sh            本地静态服务器
```

存档写在 `localStorage`（键 `zjxy.save.v4`），刷新自动恢复（连「在哪栋楼的哪一层、站在哪」一起恢复），开局可点「继续上次」。`?seed=123` 可固定随机种子复现。

## 测试

```bash
node tests/sim.mjs     # 800 局（8 种打法 × 100 种子）
node tests/maps.mjs    # 7 张室内图 + 校园门口 + 5 个活动出发点
```

`sim` 断言：心境/知识/体质/友谊在范围内、牌组不超上限、流程必定终止、同种子结果一致、摆烂拿不到高分、
三个结局都出现过、**战利品数量等于胜场数且每类加成不超封顶**、**前三次掉落必出稀有**；
另外两条是护栏 —— **只泡文娱楼（不产卡）摸不到「学神」**、**室内路线不能显著强过纯自习**。

| 打法 | GPA | 说明 |
|---|---|---|
| study | 3.15 | 3 点自由全上大课教室（心境会一路掉到见底） |
| mixed | 3.08（1.8 胜） | 学 + 社交 + 隔天夜战 |
| social | 2.48 | 只聊天 |
| lazy | 2.32 | 白天躺平（只剩必修课给的固定知识） |
| smart | 3.49（3.2 胜） | 心境低于 45 先跑操场，隔天社交；学得最多所以打得最疼 |
| indoor | 2.93 | 答疑 + 乒乓 + 大课（不夜战所以拿不到学神） |
| chill | 3.16 | 钢琴 + 乒乓 + 自习室（验证「纯心境路线」拿不到高分） |
| fighter | 3.17（4.6 胜） | 白天全上课、晚上每场都打：赢最多但 GPA 不如 smart，这就是取舍 |

结局分布 `great 22% / pass 48% / warn 30%`，目标区间 `20–35 / 30–40 / 25–40`。
`pass` 偏高是结构性的：8 种打法里只有 `smart` / `mixed` / `fighter` 会打夜战，其余 5 种拿不到需要
「GPA ≥ 3.4 **且** 胜场 ≥ 2」的学神，只能落在 pass 或 warn。

调平衡时记住这两条口径：**必修课给固定知识，不乘心境**（否则心境拉满的 `chill` 会靠必修课白拿分）；
**体质只由操场和活动给**，所以 `study` 这类不跑操场的打法血量恒定 37，晚上更脆 —— 这是「只上课打不动夜战」的代价。

## 夜战：越打越强，也越打越难

- **敌人按夜次固定排**（拖延兽 → 冒名顶替幽灵 → 内卷王，然后循环），不再是随机抽。
  第 N 夜 `HP = 38 + 12×(N−1)`、`ATK ≈ 6 + (N−1)`。所以「今晚打谁、有多硬」是可以提前知道的，
  白天的准备才有针对性。
- **赢了掉一件永久战利品**，但只放大**出口**：夜战伤害 / 血量上限 / 白天收益，三类各自封顶 +60%。
  属性本身（知识、心境、体质）一点不动，所以 GPA 不会被战利品顶穿。
- **掉落是随机的，但有保底**：普通 60% / 稀有 30% / 传说 10%，前三次掉落里必有一件稀有以上。
- 打赢一只大约值：心境 +12、知识 +4、一件战利品。输掉是心境 −15、知识 −5。
  **赢了比「宿舍深造」强，输了比它差得多** —— 所以「今晚打不打」是一道真赌局。
  也正因为如此，第 1 夜没攒够牌就该选深造。

## 三分钟演示动线

1. **0:00** 一句话立住：白天记下的每一行笔记，晚上就是能打出去的牌。
2. **0:15** 开局就站在寝室里：先点书桌（三属性各自换算成多少伤害 / 多少血，悬停展开算式），
   再点日历墙（7 天时间轴，今天那行写着今晚要面对什么），最后问室友一句——三件都不花行动点。
   然后从左边门出去。
3. **0:40** 向上走两步到公告板按 `E`：知识 +4、和林搭上话。展示右侧「手记」。
4. **1:00** 走到 CDS-1（左上）按 `E` 进楼 → 电梯面板选 **3F 教学楼层** → 走到「大课教室」按 `E` → 面板上写着「知识 +7 / 心境 −4 / 笔记 +1 张」→ 点「开始」。右侧「牌组」跟着变长。
5. **1:20** 行动点用光自动回寝室入夜：选「宿舍深造」，指出心境掉下来以后，下次上课的收益跟着变低（HUD 里的乘数）。
6. **1:40** 第二天：先看日历墙，今天有一场「社团招新」；出寝室往左下走两步，
   社团楼门口多出一个 📌 出发点，按 `E` → 面板写着「心境 +8 / 体质 +6（血量上限 +7）」→ 出发。
   顺便指出：这是唯一能稳定涨体质的两个时间窗之一，错过就没了（日历上会划掉一条，但不扣分）。
7. **2:00** 再去操场拿「专注」（心境 +12、体质 +4），回 3F 大课教室对比同一动作的收益差（×1.5）。
   顺路去文娱楼：`1F` 的钢琴真能弹（点键或按 1–8，四个音算一首），`2F` 自习室给知识但不产卡，`3F` 祷告室心境高的时候进不去 —— 三件事说明「楼层不是菜单，是取舍」。
8. **2:20** 任一晚选「出门夜战」：出牌就是把自己的笔记砸出去；打输了心境 −15、知识 −5，说明「准备不够就别硬打」。
9. **2:45** 连点「结束白天 → 深造」到第 7 天，展示 GPA 结算与结局；三个结局的判定条件一句话带过。
10. 收尾：反派现在是占位（拖延兽 / 冒名顶替幽灵 / 内卷王），换主题只改 `data.js`；
    下一步把日历里的 ddl 变成当晚的 boss，再给夜战加永久战利品——那时打赢一只怪就不只是数字变大。
